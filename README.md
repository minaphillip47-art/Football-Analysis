# Football-Analysis
# ⚽ Football Analysis Dashboard

An interactive **Football Analytics Dashboard built with Microsoft Power BI**, designed to explore and analyze football performance across Europe's top five domestic leagues.

The project combines **data modeling, DAX calculations, interactive visualizations, custom visuals, and dashboard design** to transform football data into an intuitive analytical experience.

---

## 🏆 Leagues Covered

The dashboard currently provides dedicated analysis for:

* 🏴 **Premier League**
* 🇪🇸 **La Liga**
* 🇩🇪 **Bundesliga**
* 🇮🇹 **Serie A**
* 🇫🇷 **Ligue 1**

Each league has its own dedicated analysis pages with league-specific filtering and visualizations.

---

## 📊 Dashboard Features

### 🏠 Home Page

The dashboard starts with a centralized navigation page that allows users to move between the different leagues and analysis sections.

The interface is designed around a football-themed visual identity with custom navigation elements and league branding.

### 🏆 League Analysis

Each league dashboard provides an overview of team performance, including:

* League standings
* Team positions
* Points
* Wins
* Losses
* Goals
* Team performance comparisons
* Player statistics
* Assists
* Goal-scoring analysis

### 👤 Player Analysis

The dashboard provides player-focused statistics that can be used to identify and compare player performances, including:

* Goals
* Assists
* Player rankings
* Top-performing players

### ⚽ Team Analysis

Team performance can be explored through detailed statistics and rankings, making it possible to compare teams within each competition.

### 🔎 Interactive Filtering

The report uses Power BI's interactive filtering and drill-through functionality to allow users to move from league-level information into more detailed team and performance analysis.

---

## 🧠 Data & Analytics

The project uses a structured Power BI data model with tables such as:

* `Facts Table`
* `Teams Dim`

The analytical layer is powered by **DAX measures** to calculate and dynamically display football statistics.

Examples of analytical calculations include:

```DAX
Goals
Assists
Points
Wins
Losses
League Position
Team Rankings
```

These calculations allow the dashboard to dynamically respond to user selections and filters.

## 🎯 Project Goals

The main objectives of this project are to:

1. Transform football data into an interactive analytical dashboard.
2. Provide a clear overview of league and team performance.
3. Make player and team comparisons easy to understand.
4. Demonstrate practical use of DAX in sports analytics.
5. Build a visually polished Power BI portfolio project.
6. Create an interactive user experience rather than a static report.
